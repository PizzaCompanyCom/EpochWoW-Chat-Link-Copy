# EpochWoW-Chat-Link-Copy
Addon WoW Server Epoch Copy chat messenges and Links
**Quick Guide**
WoW Chat Copy & Links — How to Use
1. Click the minimap icon or type /chatcopy to open the addon.
2. Click [C] to copy a chat message.
3. Click [L] to copy a detected web link.
4. Press Ctrl+C to copy the selected text.
5. Use the [C] and [L] checkboxes to enable or disable chat buttons.
6. Drag the minimap icon to reposition it.
